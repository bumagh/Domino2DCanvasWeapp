## 一、项目概述

### 1.1 项目简介

这是一款基于微信小游戏平台的多米诺骨牌效应休闲游戏。玩家通过摆放骨牌，创造连锁反应，完成关卡挑战或自由创作。

### 1.2 技术栈

| 技术 | 说明 |
|------|------|
| 平台 | 微信小游戏 |
| 渲染 | Canvas 2D |
| 语言 | JavaScript (ES6+) |
| 模块化 | ES Modules |
| 物理引擎 | 自研简易物理 |

## 二、核心模块说明

### 2.1 main.js - 游戏主入口

**职责：**
- 初始化游戏各模块
- 管理游戏主循环
- 子游戏切换

**关键方法：**
```javascript
init()                    // 初始化游戏
loop()                    // 游戏主循环
enterSubGame(subGame)     // 进入子游戏
exitSubGame()             // 退出子游戏
startDominoChainGame(mode) // 启动多米诺游戏
```

**注意事项：**
- `enterSubGame()` 会调用子游戏的 `init()` 方法
- 模式设置应在 `enterSubGame()` 之后进行，避免被 `init()` 重置

### 2.2 menu.js - 主菜单

**职责：**
- 渲染主菜单界面
- 处理菜单按钮点击

**关键配置：**
```javascript
this.safeAreaTop = 50  // 刘海屏安全区域偏移

this.uiPositions = {
  startGameButton: { x: 130, y: 400, width: 140, height: 50 },
  quickChallengeButton: { x: 130, y: 460, width: 140, height: 50 },
  // ...
}
```

### 2.3 eventmanager.js - 事件管理器

**职责：**
- 统一处理触摸事件
- 分发事件到各模块
- 管理子游戏事件转发

**关键方法：**
```javascript
handleTouchStart(e)       // 触摸开始
handleMenuAction(action)  // 处理菜单动作
handleShare()             // 处理分享
```

### 2.4 domino_chain_game.js - 多米诺主游戏

**职责：**
- 游戏核心逻辑
- 关卡管理
- 物理模拟

**游戏模式：**
```javascript
this.gameMode = 'levelSelect' | 'playing' | 'freePlay'
```

**关键方法：**
```javascript
startLevel(levelId)   // 开始关卡
startFreePlay()       // 开始自由模式
exitToMenu()          // 返回（智能判断目标）
```

## 九、常见问题与解决方案

### Q1: 子游戏模式被重置

**问题：** 设置的 `gameMode` 被 `init()` 重置

**解决：** 在 `enterSubGame()` 之后再设置模式

```javascript
this.enterSubGame(sub)  // 先初始化
sub.gameMode = 'levelSelect'  // 后设置
```

### Q2: 刘海屏遮挡

**问题：** 顶部UI被刘海屏遮挡

**解决：** 添加安全区域偏移量

```javascript
this.safeAreaTop = 50
ctx.fillText('标题', centerX, 55 + this.safeAreaTop)
```

### Q3: 微信API调用限制

**问题：** `wx.shareAppMessage` 必须在用户点击事件中调用

**解决：** 确保在触摸事件回调中同步调用

```javascript
handleShare() {
  // 直接调用，不要放在异步回调中
  wx.shareAppMessage({...})
}
```
