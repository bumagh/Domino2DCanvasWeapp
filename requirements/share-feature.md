## 2. 功能概述

在游戏结束弹窗（`resultModal`）中新增"分享"按钮，玩家点击后可将当前游戏成绩分享到微信好友/群聊。

### 2.1 触发时机

- 游戏结束后，`resultModal` 弹窗显示时
- 用户主动点击"分享"按钮

### 2.2 分享内容

| 元素 | 内容 |
|------|------|
| **标题** | "我在多米诺骨牌中获得了 {score} 分！来挑战我吧！" |
| **图片** | 游戏截图（含分数叠加）或降级使用预设图片 |
| **路径** | 小游戏首页（默认） |

## 4. 微信API清单

### 4.1 主动分享 API

```javascript
wx.shareAppMessage({
  title: '分享标题',
  imageUrl: '分享图片URL或本地路径',
  query: '页面参数'
})
```

**注意事项：**
- 微信小游戏中 `wx.shareAppMessage` 需要在用户点击事件中调用
- 图片支持本地临时路径（`wxfile://` 或 `http://tmp/`）
- 图片推荐尺寸：5:4 比例，最小 500x400px

### 4.2 Canvas截图 API

```javascript
canvas.toTempFilePath({
  x: 0,
  y: 0,
  width: canvasWidth,
  height: canvasHeight,
  destWidth: 500,
  destHeight: 400,
  fileType: 'jpg',
  quality: 0.8,
  success: (res) => {
    // res.tempFilePath 为临时文件路径
  },
  fail: (err) => {
    // 降级处理
  }
})
```
